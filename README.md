## 🎶 Description (English)

**Piano** is a simple and engaging piano application  
created with **C# .NET 9.0** using **Windows Forms**.

With this project, you can play melodies using your keyboard or mouse,  
explore how sound generation works, and learn about the WinForms interface.

The project was built for learning purposes — to practice programming, event handling, multimedia, and GUI development in C#.

---

## ✨ Features

- 🎵 Realistic piano sounds (each key plays a unique tone)  
- 🎹 Supports keyboard and mouse input  
- 🎧 Adjustable volume  
- 🎨 User-friendly graphical interface built on WinForms  
- 💡 Lightweight, fast, and requires no installation

---

## 🛠️ Technologies

- **C# 12 / .NET 9.0**  
- **Windows Forms**  
- **System.Media.SoundPlayer** for sound playback  
- **Visual Studio 2022** (or any IDE supporting .NET 9)

## 🎶 Описание

**Piano** — это простое и увлекательное приложение-пианино,  
созданное на **C# .NET 9.0** с использованием **Windows Forms**.

С помощью этого проекта можно играть мелодии с клавиатуры или мышью,  
ознакомиться с принципами генерации звуков и работой интерфейса WinForms.

Проект создан для практики программирования, работы с событиями, мультимедиа и GUI в C#.

---

## ✨ Возможности

- 🎵 Реалистичное звучание клавиш (каждая клавиша воспроизводит свой звук)  
- 🎹 Поддержка ввода с клавиатуры и кликов мышью  
- 🎧 Возможность регулировки громкости  
- 🎨 Удобный графический интерфейс на WinForms  
- 💡 Лёгкий, быстрый и не требует установки

---

## 🛠️ Технологии

- **C# 12 / .NET 9.0**  
- **Windows Forms**  
- **System.Media.SoundPlayer** для воспроизведения звуков  
- **Visual Studio 2022** (или любая IDE с поддержкой .NET 9)
